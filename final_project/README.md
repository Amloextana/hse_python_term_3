ELT-пайплайн для обработки данных сервиса доставки. Данные извлекаются из сырых .parquet файлов, загружаются в базу данных, нормализуются в 3NF и агрегируются в аналитические витрины данных.  

## Структура проекта
Структура таблиц описана в **docs/tables.pdf**

- `docker-compose.yml` — конфигурация для запуска всей инфраструктуры (Airflow, PostgreSQL, pgAdmin).
- `Dockerfile` — докерфайл для сборки кастомного образа Airflow с установленными зависимостями.
- `dags/etl_dag.py` — код DAG-а для Airflow. Содержит логику извлечения данных, нормализации таблиц и построения витрин.
- `data/**.parquet` — файлы с сырыми данными.
- `init_db/` — папка с DDL-скриптом для первоначальной настройки базы данных (создание схем `raw`, `dds`, `marts` и структуры таблиц).

---

## Как запустить проект
Для запуска нужен только установленный Docker

Перейдите в корень проекта и соберите docker-compose
```bash
    cd папка_проекта/
    docker-compose up --build -d
```

## Где смотреть результаты
### 1. Панель админа Apache Airflow
- **URL:** [http://localhost:8080](http://localhost:8080)
- **Логин:** `admin`
- **Пароль:** `admin`

Dag запускается раз в сутки (00:00), так же можно принудительно запустить через панель нажав на `Trigger DAG`

### 2. Панель админа postgresql pgAdmin
- **URL:** [http://localhost:5050](http://localhost:5050)
- **Логин:** `admin@admin.com`
- **Пароль:** `admin`

1. В левом меню нажмите правой кнопкой мыши на `Servers`=>  `Register` => `Server...`
2. На вкладке **General** введите любое имя.
3. На вкладке **Connection** укажите следующие доступы:
   - Host name/address: **`postgres`**
   - Port: **`5432`**
   - Maintenance database: **`airflow`**
   - Username: **`airflow`**
   - Password: **`airflow`**
4. Нажмите **Save**.

## Как остановить проект
```bash
docker-compose down
```
